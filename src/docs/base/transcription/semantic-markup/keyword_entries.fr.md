# Mots clés

## Balisage de mots clés

[`<term>`](term.fr.md)comprend des termes pertinents pour l’histoire du droit,
si possible au nominatif.

Les mots-clés les plus importants en rapport avec le contenu de la source sont enregistrés dans
[`<keywords>`](keywords.fr.md).
Ils aident le lecteur, qui n’est pas encore familier avec la langue de la source
à trouver des documents en lien avec un sujet recherché.

## Saisie dans la base de données

Les mots clés sont enregistrés dans la 
[Base de données des termes historiques](https://termini.ssrq-sds-fds.ch)
avec une définition.

Les événements historiques sont assortis d’indications chronologiques et, si possible,
reliés au [DHS](https://hls-dhs-dss.ch/de/).

Exemple :
[Guerre de Zürich (1436-1450)](https://termini.ssrq-sds-fds.ch/views/view-keyword.xq?id=key000513)
