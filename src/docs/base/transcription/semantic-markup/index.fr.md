# 4. Balisage du contenu

Les index qui accompagnent chaque unité éditoriale n’ont pas seulement
pour but de transmettre du contenu sous forme abrégée, mais doivent
également répondre aux besoins d’une variété de groupes d’utilisateurs différents.

Les sources du droit suisse ne visent pas un public spécifique ;
au contraire, ce sont aussi bien des chercheurs de différentes
disciplines que des amateurs intéressés qui utilisent les sources.
Tous les bâtiments, les lieux et les toponymes sont balisés avec [`<placeName>`](placeName.fr.md), 
tous les noms de personnes avec [`<persName>`](persName.fr.md), toutes les collectivités, 
organisations, institutions et familles avec [`<orgName>`](orgName.fr.md)
ainsi que les entrées les plus importantes du glossaire et de
l’index thématique avec [`<term>`](term.fr.md) dans le texte
source et dans les paratextes (p. ex. dans les commentaires).

De plus amples informations peuvent être trouvées dans les pages suivantes :

- [Personnes](persons.fr.md)
- [Organisations et familles](organisations.fr.md)
- [Lieux et espaces](places.fr.md)
- [Mots clés](keyword_entries.fr.md)
- [Lemme (Glossaire)](lemmata.fr.md)
